# 质量检查清单

交付章节前使用此清单确保质量。

## 整体检查

### 基础要素

- [ ] **章节有明确标题**
  - 标题与内容相关
  - 吸引人但不过度透露

- [ ] **字数符合预期**
  - 短章节：800-1500 字
  - 标准章节：1500-3000 字
  - 长章节：3000-5000 字

- [ ] **章节完整性**
  - 有开头、发展、高潮
  - 不是片段，是完整叙事单元

- [ ] **时间地点清晰**
  - 读者知道何时何地
  - 转换时有明确标记

---

## 开头检查

- [ ] **前 3 段内抓住读者**
  - 有行动/冲突/悬念
  - 不是天气或日常流程

- [ ] **与上一章有连接**
  - 回应上一章结尾
  - 或明确时间/地点跳跃

- [ ] **背景信息不过量**
  - 没有大段信息倾倒
  - 信息自然融入动作

---

## 内容检查

### 情节推进

- [ ] **本章有核心事件**
  - 发生了不可删除的事
  - 不是"什么都没发生"的过渡章

- [ ] **推动主线剧情**
  - 揭示新信息
  - 或改变人物关系
  - 或升级冲突

- [ ] **逻辑自洽**
  - 事件因果关系合理
  - 没有巧合驱动剧情
  - 人物行为符合动机

### 冲突与张力

- [ ] **有明确冲突**
  - 人与人、人与环境、人与自己
  - 冲突推动本章事件

- [ ] **张力有变化**
  - 不是平铺直叙
  - 有紧张和缓解的交替

- [ ] **有转折或新信息**
  - 不是线性可预测
  - 有意外或新发现

---

## 人物检查

- [ ] **人物行为一致**
  - 符合已建立的性格
  - 如不一致，有解释

- [ ] **人物有反应**
  - 对事件有情绪/行动
  - 不是被动道具

- [ ] **人物有声音**
  - 对话能区分角色
  - 每人说话方式不同

- [ ] **人物展示而非讲述**
  - 通过行动/对话表现性格
  - 不是直接陈述"他很勇敢"

- [ ] **人际关系关联前置验证（新增）**
  - 本章揭示的任何"A曾经接触/威胁/盯梢过B"的关联性事实，往前追溯 3 章是否有至少**一次铺垫**？
  - 若无，标记为"巧合便利"并修改（补铺垫或推迟揭示）

- [ ] **被动角色行为痕迹检查（新增）**
  - 本章揭示的任何"看似被动角色其实在行动"的信息，往前追溯 3 章是否有至少 **2 处**铺垫？
  - 该铺垫是否"轻到不足以被识破，但重到事后能被想起"？

---

## 对话检查

- [ ] **每句对话有目的**
  - 推动情节/揭示人物/制造冲突
  - 没有"你好""吃了吗"等无意义对话

- [ ] **对话简洁自然**
  - 删除冗余词语
  - 符合真实说话方式

- [ ] **有潜台词**
  - 不是所有话都直说
  - 有言外之意

- [ ] **标签使用正确**
  - 能辨识时省略标签
  - 不过度使用副词

---

## 悬念检查

- [ ] **结尾有钩子**
  - 使用至少一种悬念技巧
  - 让读者想看下一章

- [ ] **悬念强度适当**
  - 与故事位置匹配
  - 高潮章节悬念更强

- [ ] **不是虚假悬念**
  - 不是机械误会
  - 不是无意义的"突然"

- [ ] **为下一章铺垫**
  - 设置下一章的冲突
  - 埋下伏笔

---

## 展示而非讲述检查

### 常见"讲述"标记

检查并修正以下模式：

| 讲述（避免） | 展示（使用） |
|-------------|-------------|
| 他很愤怒 | 他握紧拳头，指节发白 |
| 她很美丽 | 他凝视着她，忘记说话 |
| 他很紧张 | 他反复调整领带 |
| 房间很乱 | 衣服扔在沙发上，外卖盒堆在桌上 |
| 他很富有 | 他从口袋里掏出一叠现金 |

### 自查问题

- [ ] 是否直接陈述情绪？（改为身体反应）
- [ ] 是否用形容词总结？（改为具体描写）
- [ ] 是否跳过了关键场景？（补充展示）
- [ ] **象征点破检测（新增）**：本章是否有任何句子直接"点破"了某物品的象征意义（如"她忽然觉得这盆绿萝长得太好了，好得不像真的"）？若有，删除该句，让物品保持沉默。

---

## 节奏检查

- [ ] **句子长度有变化**
  - 没有连续 3 句长度相同
  - 长短交错

- [ ] **段落长度适当**
  - 避免大段文字墙
  - 动作场景用短段落

- [ ] **信息密度有变化**
  - 高密度（动作/对话）
  - 低密度（描写/内心）

---

## 语言检查

- [ ] **没有 AI 写作痕迹**
  - 避免"此外""然而""强调"等 AI 词汇
  - 避免四字成语堆砌
  - 句式多样化

- [ ] **"的"字不密集**
  - 没有连续多个"的"
  - 简化修饰结构

- [ ] **用词精确**
  - 避免模糊词（"一些""某种"）
  - 使用具体词汇

---

## 情绪描写模板化检查（强制）

- [ ] **本章是否使用了模板化情绪词？**
  - 禁用词库：「心沉了一下」「心跳漏了一拍」「手心出汗」「后颈发凉」「心里那层不对劲又厚了一点」「心中涌起复杂的情感」
  - 若出现，强制替换为「感官残影」写法（见 SKILL.md「深度润色」步骤）

**感官残影公式：** 情绪 = 一个反常的动作 + 一种具体的体感 + 一个与此无关的视觉残留

**错误示例（模板词）：**
```
他的心沉了一下，后颈发凉。
```

**正确示例（感官残影）：**
```
他把手机翻了个面，屏幕朝下扣在桌上。拇指正无意识地抠着手机壳边缘的磨痕——那个缺口是上周摔的。视线越过百叶窗，落在对面楼顶那块缺了笔画的广告牌上，那个字到底是什么？他想了三秒，没想起来。
```

---

## 巧合与便利检查（强制）

- [ ] **本章引入的任何外部威胁/事件**（质询信、恐吓、意外），往前追溯2章是否有铺垫痕迹？
  - 若有：铺垫是否自然、不起眼？
  - 若无：必须在前两章添加铺垫，或将事件推迟一章
- [ ] 本章是否有"恰好"出现的人/物/信息？（如"恰好路过""恰好带了钥匙"）
  - 若"恰好"出现，往前追溯是否有至少一次暗示？

---

## 信息交付克制检查（强制）

- [ ] **本章是否出现了本应属于第7章及以后的核心动机揭露？**
  - 若"是"：强制删除或改为暗示
  - 核心动机（角色的真实目的、案件的根源）必须按大纲节奏逐步释放，禁止一次性倾倒

**判断标准：** 如果本章揭示的信息足以让读者"不再需要追问下去"，则属于交付过早，必须拆解为"半真半假的替代理由"或纯暗示。

---

## 物理真实性检查（强制）

涉及以下描写后必须进行常识自查，禁止违背物理规律的情节：

- [ ] **金属老化** - 生锈/腐蚀程度是否与时间匹配？
  - 错误："生锈十年的铁管磨掉锈后发亮"
  - 正确："锈是被反复摩擦掉的，露出底下的铁灰色"

- [ ] **织物降解** - 埋藏/陈放多年的布料是否合理？
  - 错误："埋了十年的帆布一撕就开"
  - 正确："帆布被油浸过，勉强没烂透"

- [ ] **泥土痕迹** - 泥土/污渍状态是否与时间、环境吻合？

- [ ] **人体骨骼伤** - 骨骼伤情是否符合受力常识？

- [ ] **电子设备状态** - 电量/功能是否符合使用逻辑？
  - 错误："没充电的录音笔还能亮灯"
  - 正确：交代充电来源或电池状态
  - 错误："手机被攥得发烫"后依然正常显示、正常操作
  - 正确：发烫会伴随卡顿、降频、屏幕变暗，或直接死机/关机；若需表现"用力握持"，改为"指节发白""屏幕留下指纹"等不影响物理规律的描写

- [ ] **若需文学效果** - 是否给出了合理解释，而非直接违背物理规律？

---

## 生活冗余检查（强制）

- [ ] **本章是否包含至少一个与主线完全无关的生活细节？**
  - 例如：茶杯里浮动的茶叶梗、围裙上洗不掉的酱油渍、门框上贴了三年没撕的小广告
  - 目的：让读者相信这个世界在叙事之外依然运转
- [ ] 该细节是否自然融入场景，而非生硬插入？
- [ ] **反派善因的具象化检查（新增）**：如果反派的核心动机是"保护/养活一群人"，故事中是否有一个**具象化的视觉瞬间**让读者"看见"那群人（而非只是被告知）？
  - 示例：流水线女工打包药品的 5 秒钟、食堂里打饭的工人们、厂区门口等车的背影
  - 没有具象化的"三百个家庭"只是数字。有具象化的"那个女工低头装盒的动作"才是怜悯的起点

---

## 潜台词比例检查（强制）

- [ ] **每三组对话中，至少有一组是回避形态？**
  - 答非所问 / 转移话题 / 用动作代替回答 / 直接沉默
- [ ] 对话是否有"关系博弈"而不只是"信息传递"？

---

## 反向凝视检查（章节级）

- [ ] 若符合"从第5章起每隔三章"的规则，本章是否插入了非主角视角的独立段落（≤300字）？
- [ ] 该段落是否用分割线隔开，视角明确（配角/反派/旁观者）？
- [ ] 是否让读者意识到"这个世界有自己的眼睛"？

---

## 节奏缓冲区检查（章节级）

- [ ] 若前两章均发现重大线索/物证，本章是否为"无物证章"（不发现新线索）？
- [ ] "无物证章"是否完成了"让情绪沉淀、让悬念发酵"的任务？

---

## 赎罪延迟检查（章节级）

- [ ] **赎罪延迟检查（新增）**：如果本章包含"背叛→赎罪"的弧线，赎罪是否发生在背叛后的至少**一章之后**？
  - 若背叛和赎罪在同一章或相邻章，标记为"赎罪过急"并修改——让读者先经历"失去/被伤害"的痛感，再见到赎罪
  - 正确节奏：第 8 章扣证据（背叛）→ 第 9 章全程缺席 → 第 10 章才带着原件出现（赎罪）
- [ ] 背叛动机是否至少包含两层（为他人 + 为自己）？
- [ ] 背叛发生时，对方在回答前是否有可感知的沉默（至少 3 秒的可感知空白）？

---

## 反套路设计检查（大纲阶段）

大纲定稿前使用 [plot-twist-design.md](plot-twist-design.md) 检查：

- [ ] **反转种子预埋清单** - 6问至少3个答案为"是"？
- [ ] **反套路检查表** - 反派可同情、受害者不完美、好人会背叛、坏人会倒戈、主角付代价，5项全部合格？
- [ ] **三岔路法则** - 中段（40%-60%）是否设计了三条合理路径的抉择节点？
- [ ] **情感核弹** - 每个核心角色是否有"反身份"，且将在中后期引爆？
- [ ] **结局设计** - 是否符合用户在"问题6：结局的性质"中选择的结局类型（大团圆/开放式/悲剧式/惨胜式/反转型/循环式/传承式/自定义）？若用户未指定，是否避免了"全员圆满"的敷衍结尾？

- [ ] **伏笔有呼应**

  - 或即将揭示

- [ ] **时间线一致**

## 读者体验模拟检查（强制）

站在"第一次阅读的读者"视角，回答以下问题：

- [ ] **冲击点强度**：本章最想制造的冲击时刻（如方淮的沉默、"都有"），读者读到这一刻时，会下意识停顿吗？
- [ ] **回翻诱因**：本章是否有细节会让读者想翻回前面某章再看一遍？如果没有，说明铺垫不够深。
- [ ] **下一章追问**：读完本章后，读者最迫切想知道的是什么？这个追问是否具体（"他到底有没有说谎"而非"接下来会发生什么"）？
- [ ] **情绪余震**：本章结尾后，读者合上电脑去倒水时，脑子里会继续盘旋的是什么？

**检查方法：** 完成一章后，关掉文档，等 10 分钟，然后以读者身份重读——不是检查"有没有写对"，而是观察"有没有被触动"。记录下在哪个位置注意力流走了、在哪个位置停了半秒。然后回头看那个"停半秒"的段落，强化它；找到"流走"的位置，删掉或重写。

## 交付前最终检查

- [ ] 通读全文，无错别字
- [ ] 标点符号正确
- [ ] 对话标签正确
- [ ] 段落划分清晰
- [ ] 格式一致
- [ ] 如果是续章，确认与前文的连贯性

## 质量评分

交付前给自己打分（每项 1-10 分）：

| 维度 | 评分 | 说明 |
|-----|------|-----|
| 开头吸引力 | /10 | 前 3 段抓住读者？ |
| 情节推进 | /10 | 本章推进主线？ |
| 人物塑造 | /10 | 人物行为一致且有深度？ |
| 对话质量 | /10 | 对话自然且推动情节？ |
| 悬念设置 | /10 | 结尾钩子让读者想看下一章？ |
| 节奏控制 | /10 | 张弛有度？ |
| 展示而非讲述 | /10 | 用行动/对话而非陈述？ |
| 语言质量 | /10 | 无 AI 痕迹，用词精确？ |
| **总分** | **/80** | **>60 可交付，>70 优秀** |
