# Chinese Novelist: 中文小说创作助手

## 核心流程

### 第一阶段：7问确认

**使用 AskUserQuestion 工具逐一询问用户，每个问题提供选项供用户选择。**

---

**问题1：题材与风格**

```
Question: 你想要创作什么题材的小说？
Options:
- 悬疑推理（侦探、破案、解谜）
- 现代言情（都市、职场、恋爱）
- 古代言情（宫廷、江湖、穿越）
- 奇幻玄幻（魔法、异世界、修真）
- 科幻未来（科技、太空、末世）
- 武侠仙侠（江湖、门派、飞升）
- 历史架空（朝堂、战争、权谋）
- 都市现实（生活、成长、社会）
```

用户选择后记录：`题材 = [用户选择]`

---

**问题2：主角设定**

```
Question: 主角是什么设定？
Options:
- 男性主角（独角戏）
- 女性主角（独角戏）
- 双主角（男女双线）
- 群像戏（多线叙事）
```

用户选择后，如需进一步询问职业/身份，继续追问。

记录：`主角 = [用户选择]` + `职业/身份 = [用户回答]`

---

**问题3：主角性格**

```
Question: 主角的核心性格是？
Options:
- 热血正义（积极、勇敢、有担当）
- 冷静智慧（理性、谋略、高智商）
- 温暖治愈（善良、温柔、有同理心）
- 高冷孤傲（冷漠、独立、强大）
- 阴暗腹黑（心机、算计、复仇）
- 成长逆袭（从弱到强、打脸升级）
```

记录：`性格 = [用户选择]`

---

**问题4：核心冲突**

```
Question: 小说的核心冲突是什么？
Options:
- 生死存亡（生存危机、逃出生天）
- 查明真相（寻找答案、揭露秘密）
- 爱情阻碍（追求真爱、克服阻碍）
- 复仇雪恨（复仇计划、伸张正义）
- 权力争夺（竞争上位、资源争夺）
- 成长突破（自我突破、实现价值）
- 守护保护（守护重要的人或事）
```

记录：`核心冲突 = [用户选择]`

---

**问题5：章节数量**

```
Question: 你计划创作多少章？
Options:
- 10章（短篇，约3-5万字）
- 15章（中短篇，约4.5-7.5万字）
- 20章（中篇，约6-10万字）
- 30章（中长篇，约9-15万字）
- 50章（长篇，约15-25万字）
- 自定义（输入具体章节数）
```

记录：`章节数 = [用户选择]`

---

**问题6：结局的性质**

结局是读者对全书最终的印象，必须在创作前锁定方向。

```
Question: 你希望小说以什么性质的结局收尾？
Options:
- 大团圆（主要矛盾解决，主角获得幸福）
- 开放式（核心问题解决，但留白让读者想象）
- 悲剧式（主角付出沉重代价，结局带遗憾）
- 惨胜式（目标达成但失去珍贵之物，悲喜交织）
- 反转型（结尾揭晓重大反转，颠覆全书的认知）
- 循环式（结尾呼应开头，形成闭环或命运轮回）
- 传承式（主角完成使命，把责任交给下一代）
- 自定义（描述你想要的结局感觉）
```

记录：`结局性质 = [用户选择]`

---

**问题7：故事背景**

故事发生的时代与地域环境，决定语言质感、生活方式与冲突形式。可在选择后继续追问具体细节（如朝代、城市、年代）。

```
Question: 故事发生在什么背景下？
Options:
- 现代都市（大城市、写字楼、现代生活方式）
- 小镇县城（小城故事、熟人社会、乡土气息）
- 古代王朝（秦汉/唐宋/明清等，可追问具体朝代）
- 民国时期（军阀混战、新旧交替、十里洋场）
- 近代战乱（战争年代、烽火连天、家国飘摇）
- 未来科幻（近未来/远未来、科技社会、太空末世）
- 架空世界（完全虚构的地理、文明与历史）
- 异世界（穿越/异大陆、不同种族与法则）
- 修仙仙侠（宗门林立、灵界凡界、江湖与飞升）
- 自定义（描述你心中的故事环境）
```

记录：`故事背景 = [用户选择]` + `细节 = [用户回答]`

**7问收集完成后**然后进入"第二阶段：规划"。

### 第二阶段：规划 + 二次确认

执行以下步骤：

1. **创建项目文件夹**：`novels/[小说名称]/`
2. **生成大纲**：创建 `00-大纲.md`，使用 `references/outline-template.md` 模板，填入完整的章节规划
3. **反转设计检查**：执行 [plot-twist-design.md](references/plot-twist-design.md) 的强制检查：
   - 大纲生成前：回答"反转种子预埋清单"6问，**至少3个答案为"是"**，否则拒绝生成大纲并重新构思
   - 大纲初稿后：逐项通过"反套路检查表"5项，任何一项不合格必须修改角色立场或情节走向
   - 在故事中段（40%-60%进度）设计"三岔路"抉择节点，主角必须真正选择并承担不可逆后果
   - 为每个核心角色设计"情感核弹"（反身份），记录到人物档案
   - **结局设计**：按用户在"问题6：结局的性质"中选择的结局类型设计终章（如用户选择"大团圆"则设计圆满收束，选择"开放式"则设计留白余韵等），并在大纲中注明。若用户未明确选择，默认采用 [plot-twist-design.md](references/plot-twist-design.md) 中的"结尾余震模板"（代价型/回音型/镜面型）作为参考，避免"全员圆满"的敷衍结尾
4. **生成人物档案**：创建 `01-人物档案.md`，使用 `references/character-template.md` 模板，创建主角、反派、配角档案

完成后，向用户展示规划摘要并请求确认，等待用户确认。用户同意后，进入"第三阶段：疯狂创作"。

---

### 第三阶段：疯狂创作

**重要：全程无需再次向用户确认，必须逐一章创作**

按顺序逐章创作，每章执行完整的创作流程（见下方"逐章创作"），完成一章后自动继续下一章，直到所有章节完成。

---

## 疯狂创作——逐章创作流程

每章创作时严格执行以下步骤：

#### 1. 写前分析

1. 读取 `00-大纲.md` - 查看TODO list和已完成章节的摘要
2. 读取 `00-大纲.md` 中上一章的摘要
3. 更新`00-大纲.md` 中 TODO list - 将本章标记为"进行中"
4. **角色情绪状态追踪（持续追踪规则）** - 调取主角在上一章末的情绪状态（从"章节备注"中读取）。确认：
   - 如果上一章发生了触发主角旧伤的事件（如关键人物名字出现、旧物回响），本章必须在正文中**至少 3 次**通过动作/感官细节体现该情绪仍在持续。禁止一章触发、下一章立刻"回归冷静"
   - **情绪状态持续追踪规则：**
     - 当某章章末标记为"旧伤震动/迷茫"等强烈情绪状态时，下一章的正文中必须有 **至少 3 个具体动作/感官细节** 体现该情绪仍在持续
     - 检查点：在下一章写前分析时，调取上一章章末情绪状态，并在本章的正文计划中**指定 3 处**情绪体现的位置
     - 禁止一章触发、下一章立刻"回归冷静"
     - 情绪持续的形式：不是大段心理描写，而是瞬间侵袭——一个动作停顿、一个不该出现在此刻的回忆碎片、一个反常的沉默
   - 记录本次主角情绪状态到 `00-大纲.md` 本章摘要中，供下一章继续追踪
   - **执行检查：** 写完后逐段扫描，找到"情绪应出现但未出现"的段落，补充 1 个感官残影细节
5. **人际关系线索前置检查** - 检查本章计划揭示的任何"人物之间关联性事实"（如"某人盯过另一人""某人的父亲是当年主办人"），确认该关联在前文中是否有**至少一次铺垫**：
   - 如果某个关键关联（尤其是"某人盯过/接触过/威胁过另一人"）是本章才首次出现的，必须在前文（最好提前 2-3 章）补一个不起眼的暗示——某句看似随意的闲聊、某个配角欲言又止的表情、某件被当事人忽略的旧物
   - 铺垫的强度：足够让读者在事后再看时"想起曾有这么回事"，但不足以让读者在第一次阅读时就猜到
   - 示例：如果第 10 章要揭示"某人当年去盯过另一个人"，第 7 章只需让相关配角说一句"她走之前那阵子，老说有大人问她话，我问是谁她又不肯说"——一句话，就够了
6. **节奏判断** - 检查红线法则：
   - **节奏缓冲区**：若前两章均发现重大线索/物证，本章设为**"无物证章"**——不发现新线索，只写日常小事，让情绪沉淀、悬念发酵
   - **反向凝视**：若符合"从第5章起每隔三章"的规则，规划一段**非主角视角**的独立段落（≤300字），正文末尾用分割线插入
7. 设计开头钩子 - **最关键**：前20%必须有即时冲突 → [chapter-guide.md](references/chapter-guide.md)（10种开头技巧）
8. 规划场景 - 确定本章需要3-5个场景

#### 1.5 低频信息锚点追踪

1. 调取此前所有章节中出现的**「疑似锚点物品/细节」**（如特定物件、习惯动作、疤痕、某句重复出现的话）
2. 制作追踪表：

```
物品名称 | 首次出现章节 | 当前出现次数 | 计划揭示章节
```

3. 若某物品已在**连续3章内未出现**，必须在当前或下一章的自然场景中再次提及（无需强调，只需出现）
4. 若某物品出现次数已达**3次且尚未揭示含义**，触发「含义揭示倒计时」——必须在未来2章内完成揭示，否则废弃该锚点
5. 规则详见 [hook-techniques.md](references/hook-techniques.md)「低频信息锚点」

**主动追击规则（升级）：**
- 当某锚点物品在第 6 章被设定为"未来揭示的关键锚点"后，AI 必须在后续章节中**主动安排**其再次出现，而非"恰好出现"
- 最低出现频次：第 6 章设定后，第 8 章必须再次出现（一次轻量触碰），第 10 章揭示
- 两次出现之间不允许超过 2 章空白

#### 1.6 被动角色的行为痕迹追踪（强制）

如果故事中存在一个"看似被动/受害/沉默"的角色（如已故的温雨晴），其真实身份可能是"追查者/知情者/行动者"：

- 必须在**第 3-6 章之间**，至少埋下 **2-3 处"她曾经在做某件事"的痕迹**
- 痕迹形式：某配角的一句闲聊（"她走之前老往她姐姐屋里跑"）/ 一件当时不起眼的物品（一箱子没烧的画）/ 一个被误读为"悲伤"的行为（条理清楚得不像一个十五岁的孩子）
- 强度控制：足够让读者在事后回想时"记得有这么回事"，但不足以让读者第一次阅读时"猜到就是这个意思"
- 禁止在第 10 章才从零生成这条线索

#### 2. 撰写

9. 创建章节文件 - 使用`references/chapter-template.md` 模板
10. 撰写正文 - **每章必须达到3000-5000字**
    - 开头检查：前20%是否极其吸引人？
    - 对话规范 → [dialogue-writing.md](references/dialogue-writing.md)
    - **红线法则检查**（见上文"写作红线法则"）：
      - 生活冗余：本章是否包含至少一个与主线无关的生活细节？
      - 潜台词比例：每三组对话是否至少有一组答非所问/转移话题/动作代替回答/沉默？
      - 物理真实性：金属老化/织物降解/泥土痕迹/骨骼伤/电子设备状态是否符合常识？
    - 内容不足？使用 [content-expansion.md](references/content-expansion.md) 扩充技巧
11. 设置结尾钩子 → [hook-techniques.md](references/hook-techniques.md)（10种钩子类型）+ **钩子多样性法则**：禁止反复用同一种钩子形态，轮流使用感官钩子/对话回响钩子/身体反应钩子
12. **字数检查** - 必须使用脚本检查字数：`python scripts/check_chapter_wordcount.py <章节文件路径>` 低于3000字必须使用扩充技巧重写

#### 3. 撰写后优化

13. 连贯性检查 → [consistency.md](references/consistency.md) - 人物一致性、情节连贯、节奏控制
14. **深度润色（去除AI味）** - 重点检查并修改：
    - **去除过度修饰的形容词**：删减"璀璨"、"瑰丽"、"绚烂"等AI常用词堆砌
    - **减少抽象陈述**：把"心中涌起复杂的情感"改为具体动作/对话
    - **打破四字格律**：避免"心潮澎湃、热血沸腾"等陈词滥调
    - **增加口语化表达**：人物对话要有个性，避免"书面语套话"
    - **优化节奏感**：长句和短句交替，避免句式单调
    - **细节具象化**：用具体的视觉/听觉/嗅觉细节替代笼统描述
    - **情绪描写强制替换规则（感官残影公式）**：
      - 禁用词库：「心沉了一下」「心跳漏了一拍」「手心出汗」「后颈发凉」「心里涌起复杂的情感」
      - 强制公式：**情绪 = 一个反常的动作 + 一种具体的体感 + 一个与此无关的视觉残留**
      - 示例：「他把手机翻了个面，屏幕朝下扣在桌上。她发现自己的拇指正无意识地抠着手机壳边缘的磨痕——那个缺口是上周摔的。她的视线越过百叶窗，落在对面楼顶那块缺了笔画的广告牌上，那个字到底是什么？她想了三秒，没想起来。」
    - **独白破碎化检查** - 当任何角色（尤其是反派）进行"自我陈述/忏悔/解释动机"的长段独白时，检查该独白是否过于流畅、完整、逻辑清晰。一个在高压下被逼到墙角的人，说话应该是破碎的、颠倒的、夹着无意义的气声和停顿的。修改方法：
      - 把一次性说完成的内容拆成 3-4 段，每段之间插入动作（拿起杯子又放下、摘眼镜擦镜片、站起来又坐下）
      - 把他最核心的那句话（如"我把她推回去了"）放在一段长沉默之后，用比之前**更轻**而不是更高的声音说出来
      - 去掉"首先、然后、最后"等连接词，让叙述在时间线上跳跃
      - 详细写法参考 [dialogue-writing.md](references/dialogue-writing.md) 的「独白破碎化规则」段落
14.5 **写后克制检查（强制）**：
    - **动机延迟检查** - 本章是否把本应属于第7章及以后的根源性动机提前说出了？若"是"，将揭露改为"半真半假的替代理由"
    - **金句潜伏检查** - 本章是否有角色直接说出了"点题金句"或"主题总结"？若"是"，将该句拆碎为两段日常对话 + 一个动作，让伏笔藏在缝隙里
    - **巧合合理性检查** - 本章发生的外部事件，往前追溯2章是否有至少一次铺垫？若"无"，强制在前两章找一个角落补上一句不起眼的暗示，或将该事件推迟一章
    - **发现场景自然度检查** - 如果本章包含"主角发现关键证据/线索/纸条"的场景，检查该发现是否有**一个自然触发动作**，而非"主角正好伸手去摸某个地方就摸到了"。修改方法：
      - ✅ 正确：她搬运纸箱时箱子晃了一下，伸手去扶，手指碰到档案袋内侧的一个硬角
      - ❌ 错误：她翻开病历，手指伸进档案袋内侧，摸到一张折叠的纸条（动机不明，为何恰好去摸内侧？）
      - 如果发现方式过于便利，强制给发现过程增加一个"意外"——物品掉落、光线角度变化、被其他东西绊了一下——使发现看起来像偶然
    - **模板词扫描** - 用搜索工具扫描本章，检查是否含有「心沉」「心跳漏」「手心出汗」「后颈发凉」等禁用模板词。若有，强制替换为「感官残影」写法
    - **赎罪延迟检查** - 如果本章包含"前期盟友做出伤害主角选择后试图赎罪"的情节，检查赎罪行为是否**来得太快**。背叛与赎罪之间，必须有至少一个章节的"真空期"——读者需要时间"恨"这个角色，赎罪才有分量：
      - 规则：角色做出伤害性选择（如扣下证据）后，在至少接下来的一章内不出现、不回应、不解释。赎罪行为（如带来证据）必须发生在"读者已经认定他不会来了"之后
      - 错误：第 8 章扣证据，第 9 章立刻带来原件 → 背叛的痛感被赎罪抵消
      - 正确：第 8 章扣证据，第 9 章全程缺席，第 10 章才带着原件出现 → 读者经历了"他完了"的失落，赎罪才有力量
15. **字数检查** - 必须使用脚本检查字数：`python scripts/check_chapter_wordcount.py <章节文件路径>` 低于3000字必须使用扩充技巧重写

16. 生成章节摘要 - 在 `00-大纲.md` 添加摘要（300-500字）
17. 更新状态 - `00-大纲.md` 中 TODO list - 将本章标记为"完成"

1. **展示而非讲述** - 用动作和对话表现，不要直接陈述

## 写作红线法则（每章强制检查）

这些规则防止"高效推进剧情"导致文字变得太干净、太功能化，失去生活感与真实性。

### 1. 生活冗余法则

每场戏必须包含至少一个与主线剧情**完全无关**的细节。它可以是：茶杯里一片浮动的茶叶梗、围裙上洗不掉的酱油渍、门框上贴了三年没撕的小广告。**写它的唯一目的，是让读者相信这个世界在叙事之外依然运转。**

### 2. 钩子多样性法则

章节末尾**禁止反复使用同一种钩子形态**（如"掏出手机拍照""在备忘录里敲下一行字"），否则读者会审美疲劳。结尾钩子必须轮流使用以下三种形态：

- **感官钩子**：主角闻到某股不该出现的气味，愣在原地
- **对话回响钩子**：白天某人一句看似随意的闲话，此刻忽然让他后颈发凉
- **身体反应钩子**：他的手指在发抖 / 胃里抽紧 / 嗓子发干，但脸上不动声色

**钩子形态轮换表（使用范例）：**

| 章节 | 钩子形态 | 示例 |
|------|---------|------|
| 第 1 章 | 身体反应 | 后背汗湿、缩回手 |
| 第 2 章 | 对话回响 | 方淮"没下雨"+顾言"刚下过雨" |
| 第 3 章 | 突然揭示 | 顾言问"你认识温雨棠吗" |
| 第 4 章 | 感官钩子 | 闻到的气味、看到的车灯（避免再与第 1 章同为身体反应） |
| 第 5 章 | 对话回响 | 温雨晴十年前的话 |
| 第 6 章 | 承诺/威胁 | 冯立成传话"伤的是活人" |
| 第 7 章 | 离奇消失 | 顾言失踪 |
| 第 8 章 | 神秘物品 | 照片背面的字 |
| 第 9 章 | 紧急危机 | 门被反锁、灯灭了 |
| 第 10 章 | 言外之意 | 病历里的纸条 |

**注意**：如果上一章已经使用了"身体反应钩子"（出汗、发抖、心跳），下一章**必须更换为**感官钩子或对话回响钩子，禁止连续两章同形态。

### 3. 物理真实性红线

在生成任何涉及**金属老化、织物降解、泥土痕迹、人体骨骼伤、电子设备（录音笔/手机）状态**的描写后，必须进行常识自查。禁止出现"生锈十年的铁管磨掉锈后发亮""埋了十年的帆布一撕就开""没充电的录音笔还能亮灯"等违背物理规律的情节。若需文学效果，必须用合理解释（如"锈是被反复摩擦掉的，露出底下的铁灰色""帆布被油浸过，勉强没烂透"）。

### 4. 潜台词比例法则

人物对话不能只有"信息传递"，必须有"关系博弈"。**每三组对话中，至少有一组**是答非所问、转移话题、用动作代替回答或直接沉默。例如：主角问"那晚你在哪儿？"，对方不应立刻回答"我在家"，而可以是——她擦杯子的手停了停，把抹布扔进水盆，背过身说："你走吧。"

### 5. 反向凝视规则

从第5章开始，**每隔三章**，在正文末尾用分割线插入一段**非主角视角的独立段落**（不超过300字）。视角可以是：某配角关店后看着手机里家人照片的犹豫、某个反派角色半夜擦拭物件的自言自语、甚至一只蹲在墙头的猫看到的有人翻进档案室的背影。目的是让读者意识到：**这个世界有自己的眼睛，主角一直在被注视着。**

### 6. 节奏缓冲区规则

**每连续两章发现重大线索/物证之后**，必须插入一章**"无物证章"**——本章不发现任何新线索，只写主角做一件日常小事（吃面、修车、坐在河边发呆），通过他的眼睛观察周围人的表情和世界的声音。这一章的唯一任务是：**让情绪沉淀，让悬念发酵。**

### 7. 象征点破禁止法则

任何在故事中担任"沉默见证者"角色的物品/意象（如窗台上的绿萝、一块老广告牌），**禁止被作者"点破"它的象征意义**。

- 错误："她忽然觉得这盆绿萝长得太好了，好得不像真的。"
- 正确：绿萝一直在那里，每次主角看窗外时它都在。最后一页，主角离开前给它浇了水——然后走了。读者自己会懂的。

**检查方法**：搜索全文中是否有"她忽然觉得某物象征着……""某物像某种隐喻……"等作者强行总结的句子。若有，直接删除，让物品沉默地完成它的工作。

### 8. 背叛动机的多层性法则（强制）

当一个前期盟友做出伤害主角的选择时，其动机必须是**复合的、自我与他者交织的**：

- 错误模板："我是为了救我爸"（单一动机，读者可理解但不痛）
- 正确模板："我爸的事是一回事。可这案子是我经手的第一桩重启旧案——办成了是我的功，办砸了是我的过。局里的人都在看着。"（保护父亲 + 保护自己的职业声誉）

**规则：** 背叛动机至少包含两层——一层是"为他人"（可被理解），一层是"为自己"（让读者无法完全原谅）。

**执行检查：** 在背叛场景中，主角追问"为了谁"时，对方必须经历一次**足够长的沉默**（至少 3 秒的可感知空白），然后再回答。沉默本身比回答更重——读者会在这段时间里自己补完"还有我"。
